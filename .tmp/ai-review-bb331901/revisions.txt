- INPUT MODEL (new §2.1): replaced tap-car-then-tap-floor with press-and-drag on the
  shaft COLUMN. Target is the full-height column (>=44pt wide), never the 32px moving
  car. Verbs separate by gesture not cadence: drag = dispatch (floor-selector rail,
  detents, magnified label offset above thumb), tap = surge, events draw their own
  oversized control. Resolves the sub-HIG moving-target collision.
- CATCH-UP MODEL (§7.2): replaced rate-sampling with coarse-step integration of the
  same time-of-day curves at 1 step per simulated minute (4h = 240 steps). Kills the
  quit-at-rush-peak exploit (error ratio r(t0)/mean(r) was unbounded). §9's tolerance
  is now a real 1e-9 relative bound instead of an unachievable "stated tolerance".
  Elapsed clamped to [0, cap]; backwards clock treated as zero. Model evolves tenancy
  state, not just cash.
- LIFECYCLE (§7.1): three states, not two. Added HIDDEN (visibilitychange) since iOS
  Safari backgrounds without unloading and fires no reliable quit event. Save on
  hidden/focus-out + 30s timer; save-on-quit demoted to a desktop nicety. Resume and
  cold start share one catch-up path.
- STORAGE DURABILITY (§7.3): NEW. Safari ITP deletes IndexedDB after 7 days of Safari
  use without site interaction; home-screen apps are exempt. Adopted: enable PWA
  export, prompt Add to Home Screen, save export/import string, treat "no save" as a
  normal tested path. Also documented the shared github.io origin exposure.
- TICK MODEL (§8.3): physics stays 60Hz, game_root runs a 0.05s fixed-step
  accumulator. Previously ambiguous and would have run the sim 3x fast. Added the
  written intra-tick order (spawn -> move/doors -> deliver -> expire -> accrue ->
  combo), with deliver-before-expire pinned at exact-zero patience. Wall-clock
  authoritative for earnings, ticks for sim state.
- PERSISTENCE (§8.6): fixed the impossible "version checked before parse" with an
  explicit 6-step load sequence (parse -> version -> validate -> migrate ->
  re-validate -> construct). Refused load now DISABLES autosave + backs up the file
  (previously the 30s timer would overwrite a newer save with a blank). Atomic
  single-flight writes via temp+replace. RNG state, tick counter, and fractional
  accumulator added to the save schema. Save treated as untrusted input: JSON only,
  never str_to_var/bytes_to_var, never ResourceLoader.load on a user:// path,
  is_finite() on every numeric, counts clamped, string ids checked against data/.
- MILESTONE 0 REOPENED (§10.1): the probe writes before reading in the same session,
  so on Godot web (memory-backed FS synced to IndexedDB) it reports ok even when
  storage is denied. The "round-trips a save" claim was unsupported. Fix: read before
  write, report restored yes/no, verify across reload AND Safari force-quit. Added
  device exit criteria incl. background/foreground wall-clock delta and wasm memory.
